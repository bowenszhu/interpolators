template<typename index_t, int N_DIMS, int N_OPS>
class DelaunayCPUInterpolatorBase< index_t, N_DIMS, N_OPS >

Interpolator base for static/adaptive barycentric interpolator with Delaunay triangulation.

Template Parameters

N_DIMSThe number of dimensions in parameter space

Find the simplex for the given point in the given hypercube based on Delaunay triangulation. Construct the square vertex_matrix of size (N_DIMS * N_DIMS). For a simplex in 2d space with ordered vertices [0, 0], [1, 0], [1, 1], the vertex_matrix will be [[0, 1, 1], [0, 0, 1], [1, 1, 1]] where the elements in the first two rows and the first column corresponds to the first vertex [0, 0], the elements in the first two rows and the second column corresponds to the second vertex [1, 0], and the elements in the first two rows and the last column corresponds to the last vertex [0, 0]. The last row are all ones.

Parameters
[in]hypercubeThe lower-left vertex of the hypercube in indexed supporting points
[in]scaled_pointThe scaled coordinate of the given point inside the hypercube
[out]vertex_matrixMatrix of simplex vertices
[out]simplexArray of vertices of the simplex
