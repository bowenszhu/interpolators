Detailed Description

template<typename index_t, int N_DIMS, int N_OPS>
class LinearStaticCPUInterpolator< index_t, N_DIMS, N_OPS >

Static piecewise linear interpolator.

Template Parameters
index_tindex type used for supporting point indexing
N_DIMSThe number of dimensions in parameter space
N_OPSThe number of operators to be interpolated
